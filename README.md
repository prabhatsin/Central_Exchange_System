Central Exchange System

A Binance-inspired centralized cryptocurrency exchange built from scratch in Python.

This project aims to replicate the core architecture of a modern exchange, including order management, balance management, order books, matching engines, trade execution, and settlement.

Current Scope

Currently implementing the Spot Trading Engine with support for:

User accounts
Balance management
Fund locking
Limit orders
Market orders
Order books
Matching engine
Trade execution
Settlement
Tech Stack
Python
FastAPI
PostgreSQL
SQLAlchemy
Redis
Docker
